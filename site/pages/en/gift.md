# A place in the Alpha, as a gift

Someone who already uses Ownpace has given you a gift card. It holds a code you use to ask for
access to the Alpha.

## What a gift is {#what-a-gift-is}

The Alpha of Ownpace is free and by invitation. Each person in it may give one person a place as a
gift. A gift is a warm introduction, not a key: we read every request and say yes ourselves. Your
request reaches us marked as a gift from the giver.

If we say yes, you get your own organisation in Ownpace. You do not join the giver's, and the giver
sees nothing of your data.

## Using your code {#using-your-code}

1. Open the [Request access]([[REDEEM]]) page. The field for the gift code is already open.
2. Type the code as it is on the card. Capitals and dashes do not matter.
3. Fill in the email address where you want to hear from us, and send the request.

A code works once. It is valid for two years, unless it is used or revoked first. If it does not
work, ask the giver for a new one.

## What we keep {#what-we-keep}

Of the gift we keep who gave it, a fingerprint of the code (never the code itself), when it was
made and used, and which request it became. We never see your name or the message on the card. We
keep your request as we keep any request; the [privacy policy](./privacy.html) says for how long.
