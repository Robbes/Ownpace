## What this is

The extraction that unblocks three features, plus the smallest honest fix for "the docs are
filenames a browser cannot open".

The rule worth keeping from it: **describe the inputs in one place, keep the stored shapes in
another.** What a person types is a UI concern and changes when a provider renames a button;
what gets stored is a contract with the connectors and changes only when they do. Collapsing
the two would have been less code and one drift away from a form that cheerfully collects
values nothing reads.
